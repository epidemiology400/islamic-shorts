# خط إنتاج الفيديوهات الإسلامية القصيرة

ينتج فيديو MP4 بمقاس 9:16 ودقة 1080×1920، جاهزاً للنشر على YouTube Shorts وTikTok: مقاطع مرخّصة، تعليق صوتي، ترجمة عربية متزامنة، تدرج لوني سينمائي، وجهارة صوت ‎-14 LUFS.

```
episodes/<الحلقة>/
  episode.json     النص والجمل وتوقيتها والمشاهد والإعدادات
  vo_master.wav    التعليق الصوتي (أو يُولَّد بأمر tts)
  clips/           مقاطع مرفوعة يدوياً (اختياري)
  licenses.csv     سجل ترخيص كل مقطع مرفوع يدوياً
  out/             الناتج: MP4 + SRT + تقرير التراخيص + نص النِّسبة للوصف + صورة مراجعة
```

## الأوامر

| الأمر | ماذا يفعل |
|---|---|
| `python3 produce.py doctor` | يفحص الأدوات والخطوط والمفاتيح، ويختبر الاتصال بكل خدمة |
| `python3 produce.py check episodes/ep01` | يعرض المشاهد ومصدر وترخيص كل مقطع، ويذكر الناقص |
| `python3 produce.py tts episodes/ep01` | يولّد التعليق من ElevenLabs ويوقّت الترجمة تلقائياً |
| `python3 produce.py align episodes/ep01` | يوقّت الترجمة على ملف صوتي موجود (Whisper إن وُجد، وإلا ElevenLabs Scribe) |
| `python3 produce.py fetch episodes/ep01` | يختار مقطعاً لكل مشهد ويجلبه: Pixabay أولاً ثم Pexels |
| `python3 produce.py render episodes/ep01` | المونتاج والإخراج النهائي، ثم فحص المواصفات |
| `python3 produce.py all episodes/ep01` | من البداية إلى النهاية |

## مصادر المقاطع وقواعد التراخيص

يرفض الخط أي مقطع بلا سجل ترخيص، وأي مصدر غير موجود في هذه القائمة:

| المصدر | الطريقة | الترخيص | ملاحظات |
|---|---|---|---|
| Pixabay | آلي (API) أو يدوي | Pixabay Content License: استخدام تجاري، والنِّسبة غير لازمة | تشترط Pixabay إظهار المصدر عند استعمال الـ API، لذلك يُكتب في الوصف تلقائياً، وتُخزَّن نتائج البحث 24 ساعة |
| Pexels | آلي (API) أو يدوي | Pexels License | يُنسب المصوّر في الوصف |
| Mixkit | **يدوي فقط** | **Mixkit Video Free License فقط** | المقاطع ذات «Restricted License» للاستخدام الشخصي، ويرفضها الخط. شروط Mixkit تمنع التنزيل الآلي |
| Coverr | يدوي | Coverr License | — |
| own | يدوي | تصويرك الخاص | — |

**الاختيار الآلي:** لكل مشهد عبارة بحث وبدائل. يُفضَّل المقطع العمودي، وما دقته 1920 فأكثر، وما مدته تكفي المشهد. ويُستبعد آلياً كل مقطع بوسوم مثل: نساء، وجوه، موسيقى، رموز دينية أخرى، رسوم أو مشاهد مولّدة. **ومع ذلك تبقى مراجعة صورة `contact_sheet.jpg` قبل النشر لازمة**، لأن الوسوم لا تكفي للحكم على المحتوى.

### الرفع اليدوي (عند تعذر الوصول للمصادر)

1. ضع المقطع في `clips/` باسم المشهد، مثل `clips/s04.mp4`. تُقبل صيغ الفيديو mp4 وmov وwebm، والصور jpg وpng.
2. أضف سطراً في `licenses.csv`:

```csv
shot_id,file,source,url,author,license
s04,s04.mp4,Pixabay,https://pixabay.com/videos/id-123456/,اسم المصوّر,Pixabay Content License
s09,dua.mp4,Mixkit,https://mixkit.co/free-stock-video/...,,Mixkit Video Free License
s20,dua.mp4,Mixkit,https://mixkit.co/free-stock-video/...,,Mixkit Video Free License
```

يمكن أن يستعمل أكثر من مشهد الملفَّ نفسه، ويأخذ كل مشهد منه جزءاً مختلفاً.

## الحصول على المفاتيح

### Pixabay (المصدر الأساسي، مجاني)
1. أنشئ حساباً في pixabay.com وسجّل الدخول.
2. افتح pixabay.com/api/docs.
3. في جدول «Search Videos» يظهر مفتاحك بجانب المعامل `key`. انسخه.

### ElevenLabs (التعليق والتفريغ)
1. سجّل الدخول إلى elevenlabs.io.
2. من القائمة الجانبية افتح **Developers ← API Keys**، ثم **Create API Key**.
3. اقصر الصلاحيات على Text to Speech وSpeech to Text وUser (read). انسخ المفتاح، فلن يظهر مرة أخرى.

### Pexels (إضافي، عند توفره)
من pexels.com/api اضغط **Your API Key**. إن كان إصدار المفاتيح متوقفاً فالخط يعمل بدونه.

## حفظ المفاتيح بأمان

الكود لا يقرأ المفاتيح إلا من البيئة، ولا يكتبها في ملف، ويحجبها من كل رسالة أو خطأ. اختبرنا ذلك بمفاتيح وهمية، ولم تظهر في أي مخرج.

**الأفضل: «Network secret» في إعدادات البيئة السحابية.** بهذه الطريقة يبقى المفتاح خارج بيئة العمل، ويضيفه وكيل الشبكة إلى الطلب بعد خروجه. لا يراه Claude ولا الكود، ولا يمكن عرض قيمته بعد الحفظ.

الطريق: claude.ai/code ← محدد البيئة تحت مربع الرسالة ← أيقونة الإعدادات بجانب بيئتك ← **Network secrets** ← **Add secret**.

| الخدمة | Allowed websites | Custom header | Prefix | Value |
|---|---|---|---|---|
| ElevenLabs | `api.elevenlabs.io` | `xi-api-key` | (فارغ) | مفتاحك |
| Pexels | `api.pexels.com` | `Authorization` | (فارغ) | مفتاحك |

**Pixabay حالة خاصة:** تشترط Pixabay أن يُرسل المفتاح داخل رابط الطلب (`?key=`) لا في ترويسة، فلا يصلح له network secret. ضعه في **Environment variables** في البيئة نفسها: `PIXABAY_API_KEY=...`. الكود لا يطبعه ولا يحفظه، لكن متغيرات البيئة يقرؤها أي برنامج يعمل في الجلسة، ولذلك:
- استعمل مفتاح Pixabay مجانياً مخصصاً لهذا الغرض، فهو لا يحمل بيانات دفع.
- لا تلصق أي مفتاح في المحادثة.

## إعدادات الشبكة (مرة واحدة)

في البيئة نفسها: **Network access ← Custom**، وأضف النطاقات التالية في **Allowed domains**، مع تفعيل خيار «Also include default list»:

```
pixabay.com
cdn.pixabay.com
api.pexels.com
videos.pexels.com
images.pexels.com
```

لا يلزم إضافة `api.elevenlabs.io` إن أضفته network secret، لأن مضيفات الأسرار مسموحة تلقائياً.

بعد الحفظ شغّل `python3 produce.py doctor`، ويجب أن تظهر ✔ بجانب كل خدمة.

## المواصفات التقنية للناتج

- H.264 High 4.1، yuv420p، BT.709، 30 إطاراً/ث، 1080×1920، faststart
- AAC بتردد 48kHz و192kbps، وجهارة ‎-14 LUFS، وذروة ≤ ‎-1.5 dBFS
- ترجمة محروقة على الصورة بخطوط Tajawal (السرد) وAmiri (الحديث) وAmiri Quran (الآية)، كلها بترخيص OFL وموجودة في `fonts/`. وتُسلَّم معها نسخة SRT منفصلة
- الترجمة فوق الثلث السفلي، بعيداً عن أزرار تيك توك ويوتيوب
- التدرج اللوني: ليل (ظلال زرقاء وتشبع منخفض) ← الساعة الزرقاء ← فجر ذهبي، مع حبيبات فيلمية خفيفة وتظليل للأطراف وحركة كاميرا بطيئة
- الانتقالات: قطع على إيقاع الكلام، أو ذوبان 0.5 ث متمركز على نقطة القطع فلا يتأخر التزامن

## عناصر الجذب (من الحلقة 4)

تُضبط في `episode.json`:

| الحقل | ماذا يفعل |
|---|---|
| `"hook": {"text": "...", "end": 3.0, "highlight": [...]}` | عبارة افتتاحية كبيرة أعلى الشاشة من الإطار الأول (منطقة آمنة من واجهة المنصات)، بلون التمييز مع كلمات بيضاء |
| `"style": {"karaoke": true}` | ترجمة تتبع الكلام: كل كلمة في جمل السرد تُضاء لحظة نطقها (من `build/words.json`). نصوص الآيات والأحاديث تبقى ثابتة |
| `"style": {"max_shot": 3.2}` | يقسّم كل مشهد أطول من الحد إلى لقطات متتابعة من المقطع نفسه بقفزة تكبير خفيفة، لإيقاع أسرع. صورة المراجعة تعرض أول جزء من كل مشهد فقط |
